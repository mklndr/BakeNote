# BakeNote (progress build)
React + Vite + Tailwind CSS v4 + React Router. Data is stored in the browser (localStorage).
## Done so far
Landing page, local register/login, dashboard, recipe book (add, edit, delete, search, filter, favorites, photo, print)
## Coming next
Discover (TheMealDB), baking journal, BakeNotes sticky notes, pantry, What Can I Bake?, shopping list, backups
## Run
```
npm install
npm run dev
```
